# ВРК · Головна сторінка

Прототип нової головної сторінки Всеукраїнської рекламної коаліції (ВРК), зверстаний за вайрфреймом у Figma.
Статичний сайт: HTML + CSS + JS, без збірки й без сервера. Працює на GitHub Pages «як є».

## Структура

```
index.html        — уся сторінка
css/style.css     — стилі (дизайн-токени на початку файлу, адаптив у кінці)
js/main.js        — меню, вкладки, фільтри, слайдер, анімації
assets/           — зображення (WebP), логотип (SVG)
.nojekyll         — щоб GitHub Pages віддавав файли без обробки Jekyll
```

## Як запустити локально

Відкрийте `index.html` у браузері або підніміть простий сервер у папці проєкту:

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте вміст цієї папки в корінь гілки `main`.
   ```bash
   git init
   git add .
   git commit -m "VRK homepage prototype"
   git branch -M main
   git remote add origin https://github.com/<ваш-акаунт>/vrk-homepage.git
   git push -u origin main
   ```
2. У репозиторії: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. За хвилину-дві сайт буде за адресою `https://<ваш-акаунт>.github.io/vrk-homepage/`.

Після публікації замініть у `index.html` значення `og:image` на повну адресу картинки
(наприклад, `https://<ваш-акаунт>.github.io/vrk-homepage/assets/case-honey.webp`), щоб прев'ю посилання показувалось у соцмережах і месенджерах.

## Залежності (підключені з CDN)

- [GSAP 3.12.5](https://gsap.com/) + ScrollTrigger — анімації під час прокрутки
- [Lenis 1.1.13](https://github.com/darkroomengineering/lenis) — плавна прокрутка
- Google Fonts: **Oswald** (акцентні заголовки) і **Golos Text** (основний текст)

Якщо CDN недоступний, сторінка повністю читається й працює без анімацій.
Для `prefers-reduced-motion` анімації вимкнено.

## Що ще заглушки

- Рейтинг, місця 4–10: «Назва агенції» і бали — підставити з рейтингу ВРК.
- Аналітика: «+30% / XX% / ₴XX млрд» — реальні значення з PDF досліджень ВРК.
- Відео Unpacking Ads і обкладинки новин — без реальних матеріалів.
- Innovation Awards Ukraine — немає банера й опису.
- Підписи рілзів «Агенція · нагорода — уточнити».
- Посилання на соцмережі ведуть на vrk.org.ua/contacts.html — замінити на реальні сторінки.
- Форма розсилки не надсилає дані (лише перевіряє e-mail) — підключити сервіс розсилки.
- Кадр «Ветеран-Холостяк» містить інтерфейс відеоплеєра — замінити на чистий постер.

## Права на матеріали

Логотип, фото людей, банери конкурсів, логотипи партнерів і кадри кейсів належать їхнім власникам
(ВРК, агенціям, партнерам). Перед публічним запуском варто підтвердити дозволи на використання.
3D-візуалізації стрічки й напрямів зроблені спеціально для цього прототипу.
